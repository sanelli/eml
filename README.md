# elm

ELM compiler and interpreter that converts mathematical expressions into ELM
expressions and executes them.

## Requirements

- [Alire](https://alire.ada.dev/) (`alr`) with a GNAT toolchain (`alr toolchain`)
- PowerShell (`pwsh`) for the pre-build git-commit embed script

On macOS, if linking fails with `library not found for -lSystem`, set
`SDKROOT` to your Command Line Tools SDK (for example
`/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk`) before building. The
project already passes that path to the linker when the host OS is macOS.

## Build

```powershell
alr build
```

This produces:

- `bin/elm` — compiler / interpreter executable
- `bin/elm_tests` — in-repo tests

Compiler switches treat **warnings as errors** and enable full style and
runtime checks (see `alire.toml` `[build-switches]` and `.cursor/rules/elm-build.mdc`).

## Run

```powershell
alr run
# or
./bin/elm --no-logo tokenize -i path/to/file.telm
```

### Tokenize

```powershell
./bin/elm tokenize -i filename.telm
./bin/elm tokenize -i filename.telm -o other.tokens
./bin/elm --no-logo tokenize -i filename.telm -o other.tokens
./bin/elm tokenize --no-color -i filename.telm
```

- `-i` / `--input` — required `.telm` file
- `-o` / `--output` — optional `.tokens` file; omit to write tokens to stdout
- `--no-logo` — suppress the stdout banner (use for pure dumps / pipes)
- `--no-color` — plain stderr diagnostics (no ANSI red)

Invalid tokens are reported on stderr; scanning continues and valid tokens are
still emitted. Exit status is `0` on success and `1` on CLI, I/O, or lex errors.

## Samples

`.telm` examples live under [`samples/`](samples/). Tokenize all of them with:

```powershell
./scripts/run_samples.ps1 -Operation tokenize
```

Outputs go to `.results/tokenize/` (gitignored; regenerated by the script). The script
uses `--no-logo` and `--no-color`, and exits `1` if any sample fails.

## Test

```powershell
alr run -- elm_tests
# or
./bin/elm_tests
```

Coverage includes regex automata, `.telm` tokenization (including `sinh` /
`cosh` / `tanh`), and `elm tokenize` CLI happy/negative paths.

## Layout

| Path | Role |
|------|------|
| `src/elm.ads` | Root `Elm` package |
| `src/elm-main.adb` | Main procedure (`Elm.Main` → binary `elm`) |
| `src/elm-cli.*` | CLI (`tokenize`, banner, flags) |
| `src/elm-info.*` | Program name / author / version / commit |
| `src/regex_automata.*` | In-repo regex → NFA library |
| `src/expr_tokenizer.*` | `.telm` tokenizer |
| `src/elm_tokenizer.*` | `.elm` tokenizer stub |
| `src/expr_parser.*` / `src/elm_parser.*` | Parser stubs |
| `src/ir_elm.*` | Shared IR ELM stub |
| `src/interpreter.*` | Interpreter stub |
| `tests/` | Regex, tokenizer, and CLI tests |
| `scripts/embed_git_commit.ps1` | Pre-build short-hash embed |
